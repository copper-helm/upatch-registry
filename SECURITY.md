# Security

Report privately, not in a public issue, when a upatch here:

- fails to block or detect what its README says,
- crashes, hangs or slows down a machine, or
- opens a path it should close.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Report a bug in the Linux kernel itself to the kernel security team at security@kernel.org, and a bug in shirudo through [shirudo's security policy](https://github.com/shirudo-dev/shirudo/security/policy).
